# NIPUN Basti DPMU

A single static page linking every Basti dashboard and tool, each card with a link to its GitHub repo.

**Live:** https://adichandrashekar.github.io/basti-dpmu-landing-page/

To add or reorder a link, edit the cards in `index.html`. The five main dashboards sit under "Dashboards"; smaller tools go under "More tools". No build step: GitHub Pages serves `index.html` from `main`.
